# SmartClicker

[![Check](https://github.com/m8x3a2/SmartClicker/actions/workflows/check.yml/badge.svg)](https://github.com/m8x3a2/SmartClicker/actions/workflows/check.yml)

Автокликер со своим языком скриптов, записью действий и «зрением» (поиск картинок и чтение текста с экрана).
Написан на Flutter/Dart. Сейчас работает на **Windows**. Потом будут Android и Linux.

```js
// 5 кликов по центру экрана со случайным разбросом
repeat (5) {
    click(50%, 50%, offset: 10)
    wait(800..1200)              // случайная пауза 0.8–1.2 с
}

// дождаться кнопки на экране и нажать её
if (wait_image("кнопка_играть", timeout: 30s)) {
    click_image("кнопка_играть")
}
```

## Что умеет

- **Язык ClickScript**, похожий на JavaScript: переменные, условия, циклы, функции, `try/catch`. Есть удобные записи: `50%`, `3s`, `1000..1500` (случайное число). Код от нейросети в стиле JS обычно запускается как есть.
- **Ввод**: клики, перетаскивание, удержание, колесо, клавиши и сочетания, набор текста с учётом раскладки. Есть «человечные» движения: кривые и случайный разброс.
- **Запись действий** в код: только клики, клики с остановками курсора или полная траектория. Можно привязать запись к окну.
- **Зрение**: цвет пикселя, поиск картинки (в том числе другого размера), распознавание текста (PaddleOCR встроен, есть и Windows OCR).
- **Окна и система**: работа с конкретным окном, процессы, буфер обмена, файлы, загрузка процессора и памяти, батарея, сеть.
- **Конструктор блоков** в духе Scratch: блоки и код рядом, правка мышью.
- **Отладка**: подсветка текущей строки, пошаговый режим, точки останова, просмотр переменных, проверка скрипта на ошибки до запуска.
- **Надёжность**: горячие клавиши стоп и пауза, тестовый режим без кликов, лимиты времени, перезапуск после ошибки, отчёт об ошибке одним ZIP-файлом (удобно отдать нейросети).
- **Автозапуск**: по расписанию или когда открылась нужная программа. Сворачивание в трей, мини-панель поверх окон.
- **Шаблоны** готовых скриптов, заметки, экспорт и импорт скриптов в ZIP.
- **Справка внутри программы**, которая одновременно служит готовым промптом для нейросети.

Без интернета: программа ничего никуда не отправляет. Единственное исключение — загрузка моделей распознавания, и то только по кнопке.

## Скачать

Готовая программа — ZIP в [Releases](https://github.com/m8x3a2/SmartClicker/releases): распаковать и запустить `smart_clicker.exe`, установка не нужна.

**«Windows защитила ваш компьютер».** При первом запуске скачанной программы Windows может показать синее окно SmartScreen. Это не значит, что в программе вирус. Windows помечает каждый файл из интернета и доверяет только программам с платной цифровой подписью разработчика или тем, которые уже скачало много людей. У SmartClicker подписи нет (сертификат стоит сотни долларов в год), поэтому Windows его «не знает». Что делать:
- в синем окне нажать **«Подробнее» → «Выполнить в любом случае»**;
- или ещё до распаковки: правая кнопка по ZIP → «Свойства» → флажок **«Разблокировать»** → «ОК». Тогда пометка снимется со всех файлов сразу и окно не появится.

Программу, собранную у себя (`flutter build windows`), Windows не помечает — предупреждения не будет.

## Сборка и запуск

Нужно: Flutter 3.47+, Visual Studio Build Tools 2022 с Windows SDK.

```bash
cd SmartClicker
flutter test                        # тесты
flutter run -d windows              # запуск для разработки
flutter build windows --release     # → build\windows\x64\runner\Release\smart_clicker.exe
```

Проверки на настоящей Windows (без кликов): `dart run tool/smoke.dart`. Остальные `tool/smoke_*.dart` проверяют отдельные части.

GitHub Actions (`.github/workflows/`): `check.yml` — анализ и все тесты при каждом push в `main` и в pull request; `release.yml` — сборка ZIP. Тег `v1.2.0` → тесты, сборка и релиз с ZIP; ручной запуск (Actions → Release → Run workflow) — только ZIP для скачивания со страницы запуска. Версия из тега попадает в программу (`--dart-define=APP_VERSION`, видна в отчётах об ошибках).

Данные пользователя (скрипты `scripts\*.cks`, картинки `files\`, заметки, настройки, история, отчёты) по умолчанию хранятся в `%APPDATA%\SmartClicker\`. Папку можно сменить в Настройках → «Папка с данными»: любая своя (например, в OneDrive) или «Рядом с программой» — папка `userdata` возле `smart_clicker.exe`, тогда программу со всеми скриптами можно носить на флешке.

## Устройство проекта

```
SmartClicker/lib/
  core/       логика без интерфейса (чистый Dart): язык, движок со встроенными
              функциями по темам, зрение, модель блоков, запись, хранение, отчёты
  platform/   доступ к ОС за общим интерфейсом: windows/ (dart:ffi), заглушка для тестов
  app/        приложение: state/ (состояние по частям), services/, help/ (тексты
              справки), templates/, ui/ (папка на экран, widgets/ — общие части)
SmartClicker/test/   тесты
SmartClicker/tool/   проверки на реальной системе
```

Подробная карта, правила и «как добавить команду / настройку / экран» — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

Главное правило архитектуры: **никаких Flutter-плагинов с нативным кодом**, Windows вызывается напрямую через `dart:ffi`. Единственная зависимость — пакет `ffi`.
